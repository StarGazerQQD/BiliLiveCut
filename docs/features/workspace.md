# Web 工作台与配置草稿

分析页的 7、30、90 天按 UTC 自然日统计，包含今天；概览、分布和房间排行均使用所选范围。每日趋势使用完整年月日并补齐无数据日期，跨年不会合并同月同日。录制场次及原片体积按范围内开始的场次统计，结束时间为空的场次不计入已结束数量。

先按[源码部署](../guide/source.md)准备 Python 依赖并构建前端。已准备好的环境可以一键启动前后端：

```bash
uv run --no-sync blc start --host 127.0.0.1 --port 8000
```

传统虚拟环境激活后可使用 `blc start --port 8000`。浏览器访问 `http://127.0.0.1:8000`。仅启动后端使用 `blc backend`；前端开发热更新见[前端开发](../development/frontend.md)。

## 初次见面与功能导览

首次在当前浏览器完成管理员登录后，会先显示「初次见面」，再进入工作台。本机免登录访问和恢复已有管理员会话也会触发首次引导；审核员直接进入审片页。

引导依次介绍处理流程、B 站账号、ASR 语音转写和模型服务。后台管理员登录与 B 站扫码登录相互独立；网页扫码不要求服务器具备桌面。ASR 可选择本地引擎或远程兼容 API；远程转写会把音频发送到明确选择的服务。模型连接保存地址和密钥，业务路由分别选择模型；ASR 可选择已保存的远程路由或独立 API 配置。保存不会自动测试连接，主动测试文字路由可能产生少量模型调用费用。

已有配置直接显示，只有主动申请二维码、保存配置或测试连接才会执行相应操作。引导不会自动录制、下载模型或启用自动发布。修改后需先保存或放弃本步输入，才能切换步骤；保存失败保留输入，配置版本冲突时可读取最新配置后重新确认保存。

完成设置后，可以通过导航按钮旁的气泡了解直播间、录播导入、场次时间线、审片、成品和设置中心。桌面与手机均支持，点击「下一个」继续，按 `Esc` 或点击关闭按钮结束功能导览。

所有配置均可稍后调整。点击「稍后再说」跳过后，不会在当前浏览器、当前管理员身份下反复弹出；顶部问号按钮可随时重新打开，欢迎页也可选择「只看功能导览」。浏览器只保存引导进度，不保存本次输入的 API 密钥；更换浏览器、清除网站数据后会再次引导。若浏览器禁止本地存储，仅在当前页面记住进度。

Portable Launcher 的 Web 端口可在“设置中心 → 房间自动化与端口”保存，范围为 `1..65535`。配置写入安装根目录的 `config/launcher.json`，只在下次启动 Web 时生效；源码 CLI 未传 `--port` 时也使用该保存值，显式参数优先；页面会同时显示已保存端口、当前实际端口和是否需要重启。端口被占用时会明确失败，不会随机切换端口。无密码模式仍只监听并接受 `localhost`、`127.0.0.0/8` 或 `[::1]` authority；源码/Portable 远程部署必须设置 `ADMIN_PASSWORD`；Docker 可使用一次性初始化码在网页设密。

功能概览：**直播间管理 / 录制状态 / 实时转写 / 候选审核（横屏审片工作台）/ 成品切片 / 主题管理 / 合集编辑 / 插件中心 / 运维面板 / 任务队列监控 / 上传设置**。

场次时间线的列表与详情统一按 GMT+8（北京时间）显示，并附带时区标签，不受浏览器所在时区影响。时间后的「时长」表示录制持续时间，例如 `12:54` 为 12 分 54 秒。

「错误日志」默认最新在前，可切换为最早在前，并结合等级、关键词和日期筛选。日期与日志显示均按浏览器本地时区；选择日期后会查询该天的历史记录，最多展示符合条件的最近 500 条。「清除日期」恢复不限日期，刷新保留当前筛选与排序。

插件默认从 `./storage/plugins` 读取，可通过 `PLUGIN_DIR` 修改。扫描只读取 `plugin.json`，入口代码仅在管理员显式启用后执行；插件与主程序同进程运行，因此只应启用可信插件。开发接口、清单 Schema 和最小示例见 [`plugin/README.md`](../../plugin/README.md)。

## 实时状态与断线恢复

工作台订阅当前账号可见的状态变化，再通过 HTTP 获取最新数据。服务暂时断线会自动重连；服务器重启、历史通知过期或通知格式变化时重新查询。通知只负责刷新，不会自动重复提交保存、审核、上传或取消操作，已有页面草稿继续保留。

连接正常时每 30 秒核对状态；通知不可用时继续按原页面轮询。其他后台进程的变化也通过定期核对显示。后台标签页不因通知反复请求，回到页面时刷新。登录过期会结束订阅并显示重新登录入口。一个账号同时最多建立 4 条通知连接，超限页面会退避并保留普通查询。

## 统一配置与持久化

左侧“设置中心”是唯一总入口。全部参数按录制、语音、大模型、网感、高光、审核、成片、存储、发布、通知与系统分类；可通过分类导航筛选，默认显示常用项；开启高级设置后显示完整字段，支持中文和环境变量名搜索。大模型服务商、房间自动化、账号登录、插件及模板仍有独立子页。上传和网感业务页保留运行状态，并链接到对应设置。

修改只形成内存草稿，底部展示本次影响与生效时间，点击“保存修改”才提交。切换工作台内的标签及定时刷新保留草稿；打开独立页面或重新加载前应先保存，存在未保存内容时会提示离开；校验失败定位字段，版本冲突时可读取最新值并保留草稿供核对。密码不会保存在浏览器本地存储，离开页面会提示未保存内容。模型计费单价可编辑，空白字段不会被当成删除服务商；密钥留空保持，勾选清空才删除。

`GET /api/settings/configuration` 返回当前版本的配置清单、有效值、来源、范围和生效时机；`PATCH` 接受 `values`、`reset`、`clear` 和 `revision`，整体校验后一次提交。Web 覆盖优先于环境/项目默认，重启后保留。凭据不回显，留空保持，显式清空会阻止环境回退；恢复默认删除覆盖。正在执行的任务使用启动快照。

高光入选、进入人工审核、自动批准和自动投稿这四项全局阈值是**新房间默认值**；已有房间使用自己的保存值。自动投稿须同时满足全局自动上传、biliup、房间自动上传开启，并达到房间自动投稿阈值；否则留待人工确认。自动清理默认关闭，启用后每小时检查；清理保留活动任务、媒体使用、审核、重分析、共享文件和未登记文件。

数据库、存储根目录、插件目录、日志和登录身份仍作为启动配置，避免运行中搬迁数据或改变身份。完整字段映射及边界见 [统一配置清单](../guide/configuration.md)。
