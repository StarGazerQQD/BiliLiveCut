# 编辑判断评估与运行控制

评估工具读取已有模型结果与人工标注，不下载模型、不调用 API、不启动服务，也不初始化或迁移数据库。本轮用户缺少可用录播与标注，真实素材质量验收延期；工程测试只验证接口、数据保护和指标算法，不代表实际精确率、召回率或模型效果已达标。

## 保存实际输入与执行来源

新的编辑判断在执行开始时保存应用版本、实际安装的编辑链源码摘要、提示与策略版本、模型路由和相关预算配置，以及扩展前的原始输入。最终输入、源数据修订、执行指纹、实际提供商、请求模型、服务报告模型、请求状态、耗时和已报告用量一并保留。字段采用白名单，不导出连接地址、凭据或整个环境配置。历史记录缺少来源时保持未知，不使用导出时的新配置补造旧记录。

评估快照包含证据原文、标题和摘要，可能包含素材中的个人信息。保存在本地忽略目录，不提交 Git，也不随产品分发。向他人提供时应先确认素材授权。工具不会自动改写证据来掩盖隐私内容。

## 只读导出和场次分组

先结束相关录制和分析，再导出所需场次。参数中的路径和场次 ID 使用自己的实际值：

```powershell
python scripts/evaluate_editorial.py export --database storage/blc.db --dataset-id recordings-2026-10 --session 12 --session 13 --output .local/evaluation/snapshot.json
python scripts/evaluate_editorial.py label-template --snapshot .local/evaluation/snapshot.json --holdout-session 13 --annotator reviewer-a --annotation-version labels-v1 --output .local/evaluation/labels.json
```

输出目录须预先存在；文件只允许新建，已有快照或报告不会被覆盖。输入和输出上限均为 64 MiB，超限时减少场次数。导出通过 SQLite `mode=ro` 和 `query_only` 的同一读事务完成，保留拒绝、失败和没有候选的已确认热点及旧链窗口。合并的热点由其有效主事件表示；尚未确认的热点使整场分析保持未完成。

相同录制集合始终使用同一 `dataset-id`。在调整提示、配置或模型前确定场次级划分并保存模板：一个场次只能属于 `tuning` 或 `holdout`，不能把同场次的不同片段分到两个集合。独立评估素材不得用于调整策略；工具能检查文件中的分组冲突，无法证明标注者未看过调试结果。比较不同策略时保留相同场次划分与人工标注依据，重新绑定实际导出的快照，不手改指纹以绕过校验。

每个候选模板初始均为 `null`：

- `worth_clipping`：人工判断是否值得剪辑；未看或无法判断保持 `null`。
- `reference_bounds`：人工理想起止秒数，可为空。使用快照相同的场次时间原点，不能跨越实际录制缺口。
- `title_supported`、`summary_supported`、`decision_supported`：逐项判断现有内容是否由证据支持；未审查保持 `null`。没有实际内容的字段不能填写事实性结论。

模板不从机器推荐、技术分数或历史自动审核中生成“人工正确答案”。独立标注时先观看原始素材，再检查待评估的解释与判断。

## 固定候选与整场评估

```powershell
python scripts/evaluate_editorial.py report --snapshot .local/evaluation/snapshot.json --labels .local/evaluation/labels.json --mode fixed_candidates --output .local/evaluation/fixed-report.json
python scripts/evaluate_editorial.py report --snapshot .local/evaluation/snapshot.json --labels .local/evaluation/labels.json --mode full_session --iou-threshold 0.5 --output .local/evaluation/session-report.json
```

固定候选模式只评估人工已标注的既有对象，推荐为正预测，拒绝、待复核、缺少结果为非推荐。报告候选集精确率、候选集召回率及未标注数量，`full_session_recall` 始终为空；不能据此判断系统漏掉了多少未检测事件。

整场模式需要逐场满足以下条件，否则拒绝生成整场指标：

1. 录制正常结束、所有分段已完成分析、任务已离开分析阶段且没有未释放租约，热点没有待确认或解释中的记录。
2. 人工完整观看所有 `recording_ranges`，将相同范围填入 `watched_ranges`，`complete=true`，把全场所有值得剪辑的范围填写到 `positives`；确实没有正例时填写空列表。
3. 正例属于实际连续录制范围。录制缺口不纳入分母，缺失素材不能伪装成完整观看。

整场将机器推荐的成片范围与人工正例按指定 IoU 阈值做一对一最大匹配；重复推荐会产生额外假阳性，一个推荐不能同时覆盖多个正例而获得多次命中。报告记录匹配关系、TP/FP/FN、精确率及整场召回率。边界误差只在匹配成功的对象上计算平均绝对误差，并给出样本数；它不代表未命中对象的边界质量。机器建议与人工调整后的边界分别保留，评估使用机器候选范围。

报告分别列出调试集与独立评估集。分母为零或没有人工判断时，指标为 `null`，不会写入虚构的满分或零分。事实性来自独立人工标注，不用词汇覆盖率或模型自评充当真实依据。合成测试标签必须使用 `source=synthetic`，报告显示 `synthetic_engineering_only`；未填写的人工模板显示 `awaiting_annotation`。

## 成本与可复现性

报告绑定完整快照和标注 SHA-256、数据集、分组、标注版本、模式与 IoU 阈值。快照保留每个结果的真实输入、执行记录和策略来源。相同文件与参数产生相同报告；更换输入、配置或标注后生成新文件，不覆盖历史。

新记录包含同一共享预算的前序解释、事实核验和当前编辑请求，通过操作 ID 与请求序号去重；共享预算跨多个对象时同一请求只计算一次。费用根据实际返回用量与配置价格估算，未返回用量或价格时保持未知；同时报告已知费用部分、未知请求数和完整费用是否可知。计费范围为已保存的这些共享预算，不包含缓存原始生成的历史费用、数据库之外的调用或未持久化的崩溃请求，因此不能当作供应商最终账单。旧记录缺少前序请求成本时单独计数。

## 启停、生效边界与恢复

- 编辑判断使用已有 `analysis` 能力路由。模型管理中启用授权连接和路由后，新分析任务采用新配置；任务执行期间保留既有配置快照。没有有效路由时记录关闭或不可用状态，不伪造模型判断。现有技术候选仍可进入人工复核。
- `EDITORIAL_MODEL_MAX_ATTEMPTS` 与 `EDITORIAL_MODEL_DEADLINE_S` 限制同次操作全部请求；解释、核验、修复、重试和一次上下文扩展共享额度。参数按配置页标注在下次任务生效；使用环境变量部署时需重启服务加载新环境。
- 要暂停后续自动分析，使用房间现有自动分析开关；要阻止自动批准，使用房间自动批准开关。停止路由影响下一次任务的选择；撤销连接授权会在后续请求前再次生效。已经发出的远端请求可能仍计费，不承诺可以撤回。
- 已排队的编辑重评可在场次页或任务队列取消。作业取消及租约/代次验证阻止迟到结果提交；人工认领、草稿、边界和决定始终受保护。已有下游媒体和发布行为不会因重评撤销。
- 刷新页面通过 HTTP 恢复持久结果，SSE 仅负责通知；GET 不排队模型请求。执行失败后先检查错误类别、授权和预算，再显式预览并提交重评，避免重复点击造成无依据的费用。
- 服务中断后的作业状态按现有作业恢复机制处理；重新执行前必须取得新的有效快照。输入、配置或人工状态已经变化时旧结果不会提交。不要删除业务记录来重置状态。

本次工程验收完成后，真实素材的精确率、召回率、边界质量和事实性仍为“延期验收”，等待用户反馈提供独立素材与标注后单独核查。
