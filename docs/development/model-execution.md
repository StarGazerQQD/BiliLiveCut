# 编辑分析模型调用

`llm.call_structured` 使用现有 `analysis` 能力路由和 OpenAI SDK，通过 `ModelCallBudget` 将多步操作的次数与时间统一计算。既有 `call_text` 接口继续兼容原业务；编辑业务接入时必须在操作入口创建预算，并把同一实例传递给解释、判断、事实核验、上下文扩展和证据变化重算。

`new_editorial_budget` 从当前任务配置读取 `EDITORIAL_MODEL_MAX_ATTEMPTS`（默认 8，1–32）与 `EDITORIAL_MODEL_DEADLINE_S`（默认 180 秒，1–1800）。配置在下次任务生效。每次请求同时受 `LLM_REQUEST_TIMEOUT_S` 和总剩余时间约束；SDK 自动重试关闭。并发或递归使用同一预算会报告错误。

默认请求严格 `json_schema`。仅当服务以 400/422 明确报告不支持响应格式时，依次尝试 `json_object`、普通文本模式（不发送 `response_format` 参数，诊断记录为 `text`）；所有协议仍经过同一标准 JSON 解析器和调用方的严格字段、引用及业务校验。无效模式、认证、限流、网络错误不触发格式降级。该协商记录限于一次操作，不将一个模型的结论推广到其他路由或模型。

整个操作最多一次格式/引用修复、一次空正文重试和一次上下文扩展许可；这些请求与路由切换均消耗总预算。上下文许可由业务在实际读取扩展证据前申请，模型调用层不会自行读取媒体或补造证据。修复不回传任意异常文本或未验证的模型正文；系统说明与不可信素材保持独立消息。

请求使用独占的异步客户端，在同步分析执行线程内运行。取消与绝对截止时间会中断等待并关闭本次连接，确认请求协程退出后才返回，不遗留本地后台请求。资源清理可能继续占用时间，期间不再发送后续请求。已经发送给服务商的任务不能保证撤销，最终计费仍以服务商账单为准。单个 HTTP 成功响应最多读取 1 MiB；业务 JSON 最多 16 KiB；原始输入和模式也分别限长。

发送前和收到响应后检查最新连接授权。已撤销连接不再回退到其他路由，也不采用已返回的业务结果。每次实际请求记录请求模型、服务报告模型、格式、用途、耗时、错误及服务返回的用量。拒绝、截断和格式错误响应同样记录已知成本；推理过程不写入正文或诊断。

所有请求前检查既有每日账本，账本故障直接停止。成本仅在实际输入/输出用量与有效价格齐备时估算；缺失用量或未配置价格保留 `null`，不能声称零成本。每日限额仍是估算护栏，未知用量与并发请求使其无法替代服务商账户硬限额。总请求次数和时间上限始终生效。

验收使用真实 SDK 与受控 HTTP 边界，并保留本机真实回环 HTTP 集成测试。不需要提供商密钥，不用模拟模型结果宣称真实剪辑质量提高。
